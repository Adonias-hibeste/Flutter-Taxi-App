# 🚖 Taxi

**Reliable. Professional. Real-time.**

Taxi is a high-fidelity ride-hailing showcase built with Flutter. It features a modern map-centric interface, precise fare estimation, and a premium user experience designed for professional urban transportation services.

![Taxi Header](https://raw.githubusercontent.com/Adonias-hibeste/Flutter-Taxi-App/main/preview.png)

## ✨ Features

- 📍 **Map-Centric Interface** — Seamlessly integrated Google Maps for real-time location tracking and route visualization.
- 🚕 **Multi-Vehicle Support** — Choose between Basic, Comfort, and XL vehicle types with clear pricing.
- ⏱️ **Live Arrival Estimates** — Dynamic calculation of driver arrival times based on traffic and distance.
- 💳 **Fare Estimation** — Transparent pricing model with instant trip cost calculation.
- 🌓 **Premium Taxi Theme** — High-contrast black and yellow aesthetic for maximum visibility and brand recognition.
- ⚡ **Riverpod Integration** — Robust state management for handling trip statuses and map interactions.

## 🛠️ Tech Stack

- **Framework**: [Flutter](https://flutter.dev)
- **Maps**: [Google Maps Flutter](https://pub.dev/packages/google_maps_flutter)
- **Location**: [Geolocator](https://pub.dev/packages/geolocator)
- **State Management**: [Riverpod](https://riverpod.dev)
- **UI/UX**: [Lucide Icons](https://pub.dev/packages/lucide_icons), [Google Fonts](https://fonts.google.com)
- **Architecture**: Clean Architecture (Feature-first modular)

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Adonias-hibeste/Flutter-Taxi-App.git
   ```
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Add your Google Maps API Key to `AndroidManifest.xml` and `AppDelegate.swift`.
4. Run the app:
   ```bash
   flutter run
   ```
